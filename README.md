# 環境知識競賽題庫系統（Web 版）

可直接上傳至 GitHub 並啟用 **GitHub Pages** 使用（純靜態網頁，無需後端）。

## 檔案結構
- `index.html`：主系統頁面（登入、年段選擇、測驗、錯題本、管理者後台）
- `data/questions_國小.js`：國小組題庫（按需載入）
- `data/questions_國中.js`：國中組題庫（按需載入）
- `data/questions_高中職.js`：高中職組題庫（按需載入）
- `data/questions_社會.js`：社會組題庫（按需載入）

## 登入方式
- **一般使用者**：直接從下拉式選單選擇姓名／帳號即可進入練習（由管理者於後台建立名單）。
- **管理者**：切換至「管理者登入」，預設帳號 `admin`、密碼 `1234`（登入後可新增／管理使用者，並查詢或匯出 CSV / JSON 使用紀錄）。
